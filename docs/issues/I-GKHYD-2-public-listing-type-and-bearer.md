Implements FS-GKHYD §Requirements 1–4, 11, 14, §API surface (HTTP rows)

## What to Build

- **Gateway** (`internal/gateway/listing/model.go`, `typed.go`):
  - Add a public listing type: today's `Listing` minus `sellerId`, `buyerId` and `soldPrice`, plus a required `own: boolean`.
  - Add a public page type wrapping it.
  - browse-listings and get-listing answer the public types. list-my-listings keeps today's `Listing` / `ListingPage` unchanged, with no `own`.
  - The item embed (`embedItems`) must serve both types.
- **Bearer:** both public operations take an optional, hidden `Authorization` header. When it is present they forward it (`withBearer`); when it is absent they send none. They stay public: no protect middleware, no security requirement, never 401.
- **Docs:** update the two operation descriptions (no member ids; `own`; an invalid token reads as anonymous).
- **Contract:** run `make openapi && make client`. Add `game-server/.oasdiff-ignore` lines for each removed response property on each operation, with a WHY comment citing FS-GKHYD (owner to review). Confirm that `make openapi-breaking` fails without them and passes with them.
